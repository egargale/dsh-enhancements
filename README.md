# dsh-enhancements

Enhancements for [DeepSeek Harness (DSH)](https://github.com/deepseek-ai/deepseek-harness): a human-in-the-loop deep-research workflow (skills + subagents + workflow tool) and a skill sync script.

- `deep-research/` — research skills and workflow, adapted from [Weizhena/Deep-Research-skills](https://github.com/Weizhena/Deep-Research-skills). See `deep-research/README.md`.
- `sync-skills.sh` — re-syncs DSH skills into `$DSH_HOME/skills` (default `~/.dsh/skills`).
